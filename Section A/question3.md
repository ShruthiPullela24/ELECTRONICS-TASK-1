# SECTION A QUESTION 3
## This Arduino sketch creates an interactive reaction time game by combining randomized delays with precise internal timekeeping. A round begins with the system waiting for a random interval between two and six seconds before turning on an LED to signal the user. To prevent users from simply holding the button down to get a score of zero, the code includes a check; if it detects the button is pressed before the LED turns on, it aborts the round, scolds the user via the Serial Monitor, and resets. Once the light finally illuminates, the Arduino records the exact start time using the millis() function and traps itself in a loop until the button is pressed. It then calculates the user's reaction time by subtracting the start time from the current time, prints the final score in milliseconds to the screen, and waits three seconds before automatically starting the next round
