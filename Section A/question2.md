# SECTION A QUESTION 2
## This Arduino code uses a single potentiometer to smoothly control two distinct lighting effects simultaneously without ever pausing the system. It continuously reads the dial's position and uses the built-in map() function to proportionally translate that single 0–1023 raw value into two completely different working scales. First, it divides the dial's rotation into three phases, using map() to calculate the exact 0–255 brightness values needed to seamlessly cross-fade a Common Anode RGB LED through red, green, and blue (using inverted logic where 0 is fully on and 255 is off). At the exact same time, it uses map() again to scale that identical dial reading into a new timer scale, setting the blink speed of a standard LED anywhere from a rapid 50 milliseconds to a relaxed 1000 milliseconds. To ensure the smooth RGB color transitions are never interrupted, the code entirely avoids the standard delay() function; instead, it relies on the Arduino's internal millis() stopwatch to seamlessly track time in the background and toggle the blinking LED only when the precise, newly mapped interval has passed.
